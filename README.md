## 🎯 About TOURNaX

TOURNaX aims to make competitive Free Fire gaming more accessible by providing players with a dedicated platform to discover and participate in tournaments.

Built around the esports experience, TOURNaX focuses on competitive matches, tournament discovery, and a modern gaming interface.
